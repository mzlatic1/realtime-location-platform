# Privacy

The demo uses synthetic data and is not compliance certification. Real deployment needs
informed consent, purpose limitation, minimal precision/retention, deletion workflows,
role-based access, employee-access audits, encryption, key rotation, aggregation/fuzzing,
incident response, and jurisdiction-specific review. Historical and current-state deletion
must include archives, caches, and downstream copies.

Loading the dashboard requests basemap tiles from CARTO, which can see the viewer's IP
address and map viewport. No device or location-event data is sent to CARTO. Review that
third-party disclosure before any non-demo deployment.
